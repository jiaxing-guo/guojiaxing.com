## Central Question

Can learned models guide public-belief search without hiding strategic failure in imperfect-information games?

## Main Contribution

This project develops research tools that connect learned models with public-belief search. A public belief gives the system a common state for reasoning when players hold different private information.

The repository emphasizes measurable search behavior, reproducible evaluation, and a clear boundary between learned guidance and strategic computation.
