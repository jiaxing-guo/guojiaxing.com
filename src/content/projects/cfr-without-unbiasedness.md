## What it contains

This project packages code and results for experiments with Counterfactual Regret Minimization.

The implementation supports direct inspection of algorithmic choices and their experimental effects.

## Why it exists

The repository provides a compact environment for testing which assumptions are necessary for reliable regret-minimization behavior.
